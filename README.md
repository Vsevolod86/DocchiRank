# DocchiRank

Расставь аниме, мангу и ранобэ из Shikimori по своим предпочтениям с помощью попарных сравнений.

Название сочетает японское *docchi?* («что из двух?») и английское *rank* («место в рейтинге»).

## Запуск

Нужны Node.js 24 и pnpm 11.25.0. Выполни команды из корня проекта.

```powershell
pnpm install --frozen-lockfile
pnpm dev --port 4173 --strictPort
```

Открой [DocchiRank](http://127.0.0.1:4173/) и попробуй демонстрацию.
