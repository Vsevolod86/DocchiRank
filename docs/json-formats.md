# JSON в DocchiRank

Приложение скачивает `docchirank-*.json` для резервной копии и `*-docchirank.json` для импорта оценок в Shikimori. В примерах поля поясняются комментариями `//`.

## Выгрузка для Shikimori

DocchiRank проверяет, что категория файла совпадает с категорией коллекции, и по `target_id` подставляет итоговую оценку в поле `score`. Остальные поля, строки без итоговой оценки и порядок строк сохраняются.

Новые тайтлы добавляются в конец файла со статусом `planned`, `rewatches: 0` и `text: null`. Для аниме используются `target_type: "Anime"` и `episodes: 0`. Для манги и ранобэ используются `target_type: "Manga"`, `chapters: 0` и `volumes: 0`. Окно скачивания показывает список добавляемых тайтлов.

```jsonc
[
  {
    "target_title": "Steins;Gate",
    "target_title_ru": "Врата Штейна",
    "target_id": 9253, // ID аниме в Shikimori.
    "target_type": "Anime",
    "score": 9, // Итоговая оценка DocchiRank для этого тайтла.
    "status": "completed",
    "rewatches": 2, // Число повторных просмотров.
    "episodes": 24, // Число просмотренных серий.
    "text": null // Заметка пользователя.
  }
]
```

## Резервная копия коллекции

DocchiRank читает копии версии 2 с кратким снимком сессии. Снимок содержит вход, настройки и журнал. При открытии движок вычисляет текущую пару и размещённый порядок. Коллекция без сессии содержит отдельное поле `orderedIds`. Для манги и ранобэ в `collection` есть `"media": "manga"`. При отсутствии поля коллекция относится к аниме. Поля `animes` и `animeId` хранят сведения и ссылки на тайтлы обеих категорий.

```jsonc
{
  "schemaVersion": 2, // Версия формата резервной копии.
  "collection": {
    "profile": { // Источник списка и его владелец.
      "id": "example_animes.json", // ID профиля или имя файла для файлового источника.
      "nickname": "example",
      "url": null,
      "source": "shikimori-json" // shikimori, shikimori-json, saved-selection или demo.
    },
    "animes": [ // Публичные сведения о произведениях.
      {
        "id": "9253", // ID аниме в каталоге Shikimori, записанный строкой.
        "name": "Steins;Gate",
        "russian": "Врата Штейна", // Русское название или null.
        "url": "https://shikimori.io/animes/z9253-steins-gate",
        "communityScore": 9.07, // Дробная оценка сообщества или null.
        "kind": "tv", // Тип аниме, например tv или movie. null означает неизвестный тип.
        "coverUrl": "https://shikimori.io/system/animes/original/9253.jpg" // HTTP(S)-ссылка или null.
      }
    ],
    "entries": [ // Записи исходного списка с личными данными.
      {
        "id": "json:9253", // ID записи списка. Для импорта из файла используется префикс json:.
        "animeId": "9253", // Ссылка на animes[].id.
        "status": "completed", // Статус просмотра, например completed. Неизвестный статус записывается как null.
        "originalScore": 9, // Оценка владельца списка в Shikimori или null.
        "importedAt": "2026-11-22T00:00:00+07:00" // Время импорта в формате ISO 8601.
      }
    ],
    "id": "shikimori-json:example_animes.json", // Устойчивый ключ коллекции в браузере.
    "name": "example", // Имя коллекции в интерфейсе.
    "selectedIds": ["9253"], // ID аниме, отмеченных для сравнения.
    "session": { // Текущая сессия сравнения. До её запуска здесь null.
      "schemaVersion": 2, // Версия структуры сессии.
      "algorithmVersion": 1, // Версия алгоритма воспроизведения журнала.
      "sessionId": "example-session",
      "input": { // Неизменяемый вход на момент начала сессии.
        "known": [], // Готовая база K. Каждый вложенный массив — группа равных.
        "pending": ["9253"], // Исходный порядок ID. Определяет порядок внутри ничьих и выбор следующей пары при пропуске.
        "queue": ["9253"] // Те же ID по оценкам на момент начала сессии. После обновления оценок очередь сохраняется.
      },
      "options": {
        "strategy": "insertion", // Выбранная стратегия: insertion или merge.
        "gallopThreshold": 3 // Число побед блока подряд перед ускоренным поиском при слиянии.
      },
      "history": [] // Полный журнал. Один тайтл размещается без вопросов.
    },
    "ratings": { // Шкала оценок DocchiRank для установленного порядка.
      "topScore": 9, // Оценка верхнего интервала или null, пока оценки не назначены.
      "boundaries": [ // Границы интервалов с разными оценками.
        {
          "aboveId": "9253", // ID аниме непосредственно выше границы или null у края.
          "belowId": null, // ID аниме непосредственно ниже границы или null у края.
          "scoreBelow": 7 // Оценка для интервала сразу ниже границы.
        }
      ]
    },
    "archivedSessions": [] // Прежние сессии в том же формате, что и session. Поле необязательно.
  }
}
```

### Журнал сравнения

После ответа в `session.history` появляется событие. Журнал сохраняет и ответы, которые позже отменили или пересмотрели.

```jsonc
[
  {
    "id": "two-title-session:1", // ID события в виде sessionId:sequence.
    "sequence": 1, // Порядковый номер в журнале.
    "type": "answer", // answer, undo или revise.
    "leftId": "5114",
    "rightId": "9253",
    "answer": "right", // left, right, tie, skip либо null.
    "targetEventId": null, // ID исходного события для отмены или пересмотра.
    "affectedIds": [] // ID решений, затронутых подтверждённым пересмотром.
  }
]
```

### Ручной старт и перенос оценок

После сброса оценок `ratings` может содержать дополнительный флаг:

```jsonc
{
  "topScore": null, // Оценки пока не назначены.
  "boundaries": [],
  "manualStart": true // Начать с оценки в строке и при повторном открытии сохранить ручной режим.
}
```

При пересмотре мест или дополнении списка с оценками в `collection.ratingTransition` временно могут храниться:

```jsonc
{
  "scores": { "9253": 9 }, // Прежние оценки по ID аниме.
  "changedIds": ["9253"], // Аниме, которым нужно заново определить интервал.
  "choices": {} // Необязательные ответы на стыках в виде «ID аниме → выбранная оценка».
}
```

## Указатель продолжения

В localStorage хранится ключ последней открытой коллекции. [Ключ указателя](../src/storage/selection-store.ts)

```jsonc
{
  "collectionId": "shikimori-json:example_animes.json" // Ключ коллекции в IndexedDB.
}
```

## Запись IndexedDB

Хранилище `collections` записывает поля резервной копии и целое поле `revision`. Версия позволяет обнаружить параллельное сохранение из другой вкладки. [Настройки базы](../src/storage/collection-database.ts)
